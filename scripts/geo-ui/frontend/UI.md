# Geo UI — визуал v1

Согласовано 2026-08-20 (компаньон). Характер: светлая админка как Keenetic.

## Поверхность

Фон `#eef1f4`, карточки `#fff`, текст `#1a1a1a`, акцент `#2f6fed`, RU-секция `#0d9488`, ошибка/коллизия `#c43c3c`. Шрифт system-ui. Лог: фон `#1e1e1e`, текст `#c8e6c9` / `#ddd`, ui-monospace. Без UI-kit.

## Layout (100vh)

- Слева ~200px: «Geo», список групп (`title` + `description` одной строкой серым), внизу «+ Группа».
- Справа сверху: `title` группы + `description`, переименовать / удалить.
- Справа середина (flex 1, scroll): секции записей.
- Снизу панель «Применение»: лог apply, автоскролл, строки как в консоли.
  - высота меняется перетаскиванием верхней кромки (сохраняется в localStorage);
  - можно скрыть (полоска 28px) или развернуть на весь экран.

Мобильная вёрстка не нужна.

## Секции

- Две карточки: `blocked-sites` (VPN / WireGuard) и `only-ru` (прямой RU).
- Контейнер: `display: flex; flex-wrap: wrap; gap`. Карточка: `flex: 1 1 280px`.
- Широкий экран (≥ ~900px): две колонки. Узкий: друг под другом.
- В UI **нет** кнопки «+ Секция». В коде секции рендерятся циклом по списку сетов (`SETS`), чтобы позже добавить третий сет правкой константы, не вёрстки.

## Добавление записи

Пустая строка внизу **этой** секции. Слева выпадашка типа (`domain` / `ip/cidr` / `geosite` / `geoip`), справа значение без префикса. Enter сохраняет. Для geosite/geoip — подсказки тегов по алфавиту.

## Коллизии

Жёлтый фон строки / поля; текст `уже в "⟨группа⟩", ⟨сет⟩`. Сохранение не блокировать.

## Перенос

Между сетами — действие на строке (в другую секцию той же группы). В другую группу — тоже действие на строке, не drag-and-drop в v1.
